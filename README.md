# OOD Generalization Study: SFT vs. RL Alignment Analysis

Экспериментальное исследование генерализации модели **Qwen2.5-1.5B-Instruct** вне обучающего распределения (Out-of-Distribution) при переносе методик из работы *«SFT Memorizes, RL Generalizes» (ICML 2025)*.

---

## 📌 Основные результаты (Key Findings)

В ходе серии экспериментов зафиксирован **классический сдвиг распределения (OOD Shift)**:
* **Рост In-Distribution (ID):** Модель успешно фиксирует паттерны и демонстрирует уверенный рост метрик на обучающем распределении.
* **Падение Out-of-Distribution (OOD):** На OOD-тестах зафиксирована деградация качества, вызванная меморизацией коротких стратегий вместо усвоения абстрактных математических правил.

---

## 🔬 Анализ ошибок и эффекты

1. **SFT без Chain-of-Thought (CoT):** На базовых этапах без явного CoT полиси-модель склонна к угадыванию ответа, что затрудняет генерацию корректных траекторий для RL.
2. **Reward Hacking:** Разбиение награды на промежуточные шаги (Step-wise Rewards) привело к тому, что модель научилась максимизировать частичный сигнатура-ревард, игнорируя итоговую математическую строгость.
3. **Требования к верификатору:** Подтверждена гипотеза о том, что устойчивость RL-дообучения напрямую зависит от жесткости верификатора траекторий во избежание свала в оверфиттинг.
4. **Аналог аугментаций для GP24-L:** Без случайного перемешивания набора карт в тренировочном датасете модель оверфитится на возрастающие последовательности. Это приводит к заучиванию частых структур ответов и резкому падению качества на ID-выборке.

---

## 🛠 Технологический стек

* **Base Model:** `Qwen2.5-1.5B-Instruct`
* **Frameworks:** PyTorch, TRL, Transformers, Datasets, WandB
* **Methods:** Supervised Fine-Tuning (SFT), Reinforcement Learning (GRPO)
